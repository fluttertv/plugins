## Addendum: manual fixes + verification

`firebase_ai` is unusual among the Firebase plugins: its heavy lifting (Gemini /
Imagen calls) happens in **Dart over HTTPS**, and its native layer is a single
method channel (`getPlatformHeaders`, returning the bundle id). So there is **no
Firebase native SDK** to link. Applied by hand:

- **Podspec:** tvOS 15.0 floor; `static_framework`; no Flutter-CocoaPod dependency
  (Flutter via `FRAMEWORK_SEARCH_PATHS`). **No `Firebase/*` or `firebase_core_tvos`
  pod dependency** — the native side doesn't touch the Firebase SDK.
- **Deleted the generated `tvos/Package.swift`** (route via the podspec).
- **`lib/firebase_ai_tvos.dart`:** one-line re-export of
  `package:firebase_ai/firebase_ai.dart` (the Dart API is platform-agnostic —
  duplicating would create incompatible types). Copied Dart removed.
- **No `firebase_core` import repoint needed** — `FirebaseAIPlugin.swift` doesn't
  import `firebase_core` at all.
- **pubspec:** depends only on `firebase_ai ^3.13.1` (no `firebase_core_tvos` — the
  consuming app brings that for `Firebase.initializeApp`).

**Version alignment:** `firebase_ai 3.13.1` is on the `firebase_core 4.11.x` train
(the same train as `firebase_core_tvos`). Keep the whole Firebase stack on one
consistent FlutterFire release.

**Verified (runtime):** on **both** the tvOS simulator (26.2, Apple TV 4K) and a
**physical Apple TV 4K (release/AOT)** against a live Firebase project with AI
Logic enabled. `FirebaseAI.googleAI().generativeModel('gemini-flash-latest')`
`.generateContent(...)` executed on tvOS, the request reached the Gemini backend,
was **authenticated**, and the **model resolved** — confirmed on-device by writing
the backend reply to the app container and pulling it off with `devicectl device
copy from`. The generated-content payload additionally requires the Firebase
project to have Gemini API billing/credits (the test project's were depleted, so
the backend returned a billing message — which itself proves the full
native→Dart→backend round-trip works on tvOS).
`Platform.operatingSystem == "tvos"` / `Platform.isIOS == true`.
