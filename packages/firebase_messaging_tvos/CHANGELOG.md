## 0.0.3

* **Fix:** ship the privacy manifest in the app. `PrivacyInfo.xcprivacy` was in
  the package but declared by neither the podspec nor `Package.swift`, so it
  never reached the built app, and App Store uploads could be rejected with
  ITMS-91061. It moves to `tvos/Classes/Resources/` (SwiftPM only bundles
  resources inside the target directory) and is declared in both, as upstream
  does.

## 0.0.2

* Add Swift Package Manager support: ships `tvos/Package.swift` (one Objective-C
  target, with `firebase_core_tvos` as the sibling package
  `../firebase_core_tvos`). flutter-tvos links a plugin that ships
  `tvos/Package.swift` through Swift Package Manager and leaves it out of the
  Podfile.
* Requires `firebase_core_tvos: ^0.0.4`, the first version with a
  `tvos/Package.swift`. firebase_core_tvos 0.0.4 is no longer in the Podfile, so
  this package's podspec could not resolve its `firebase_core_tvos` dependency.
* Imports firebase_core_tvos's headers as `<firebase_core/...>` when
  `<firebase_core_tvos/...>` (the CocoaPods layout) is not there.
* `LIBRARY_VERSION` (podspec and Package.swift) now matches the package version.
  It said 0.0.1.

## 0.0.1

* Initial tvOS scaffolding generated by `flutter-tvos plugin port` from
